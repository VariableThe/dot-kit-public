# Local Beeper Integration

Interact with a Beeper instance via a local MCP bridge.

## Prerequisites
- An active Beeper Desktop instance.
- A local MCP bridge running at the designated endpoint.
- Proper authorization to the Beeper API.

## Operations
- Send and read messages in Beeper chats.
- Focus specific chats or jump to messages.
- Manage drafts and attachments.

## Authorization
Access is managed via the local MCP bridge; ensure the bridge session is authenticated.

## Limits
- This integration depends on the local bridge availability.
- Only supports targets allowed by the Beeper MCP API.
